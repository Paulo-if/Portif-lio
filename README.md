# Portfolio - Paulo Otavio Costa Santos

A modern, sleek, and fully responsive personal portfolio website built to showcase my skills, projects, and background as a Software Developer.

## Live Demo

View the live website: https://www.otaviopaul0.com.br/

## Features

- **Fully Responsive Design:** Optimized for mobile, tablet, and desktop screens.
- **Interactive Hero:** 3D animated background built with Three.js.
- **Scroll Animations:** Smooth reveal effects powered by GSAP + ScrollTrigger.
- **Projects Section:** Cards with live demo links to deployed applications.
- **Skills Section:** Organized skill set with brand icons.
- **Services Section:** 3D interactive background (Three.js).

## Tech Stack

### Front-end
- React / Angular
- TypeScript
- GSAP (ScrollTrigger, animations)

### Back-end & Database
- SQL / MariaDB
- Supabase
- Docker

### Tools & Workflow
- Git & GitHub
- Figma

## Project Structure

```text
portfolio/
  index.html      # Main markup (single page)
  style.css       # Global styles and responsive layout
  animations.js   # GSAP + ScrollTrigger reveal animations
  three-hero.js   # Three.js hero background
  services3d.js   # Three.js services section background
  script.js       # Auxiliary scripts (menu, interactions)
  assets/         # Images and brand icons
```
